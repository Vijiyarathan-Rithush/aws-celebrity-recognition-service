# Reflection on the Project – AWS Celebrity Recognition

---

## General Reflection (Team)

This project was technically challenging but very exciting. The automated facial recognition using AWS Rekognition allowed us to apply real cloud services in practice. Achieving a high degree of automation was one of our main goals.

### What went well:

- Fully automated setup via script
- Working tests with real celebrity images
- Teamwork in implementing scripts, Lambda function, and tests

### What was challenging:

- The complexity of IAM permissions and trigger setup
- Understanding and organizing Git contributions
- Time pressure towards the end of the project

## Personal Reflection – Memeti Rejan

My main focus was on the Lambda function, IAM setup, and automated testing. I improved my Python skills and learned how to connect AWS services like S3, Lambda, and Rekognition. This project helped me gain confidence in cloud development and sparked a stronger interest in backend and infrastructure work.

## Personal Reflection – Vijiyarathan Rithush
